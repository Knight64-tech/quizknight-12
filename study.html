The Renaissance Era: Quick Notes

A period in European history (14th to 16th century) marking a cultural bridge between the Middle Ages and modern history.

  • **Key Figures:** Leonardo da Vinci, Michelangelo, Raphael.
  • **Focus:** Humanism, art, science, and exploration.
  • **Location:** Started in Florence, Italy.

JavaScript Fundamentals: Array Methods

Quick reference for the most common JS array methods.

  1. `.map()`: Creates a new array with the results of calling a provided function.
  2. `.filter()`: Creates a new array with all elements that pass the test implemented by the provided function.
  3. `.reduce()`: Executes a reducer function on each element of the array, resulting in a single output value.
